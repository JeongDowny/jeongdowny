"이게 왜 안 되지?"보다 **"어떻게 하면 되게 만들지?"** 를 먼저 생각합니다.

게임을 좋아하다가 컴퓨터공학과에 오게 됐고, 지금은 게임보다 개발이 더 재밌습니다.

직접 만든 서비스를 배포하고 사용자들의 반응을 볼 때 가장 뿌듯합니다.
